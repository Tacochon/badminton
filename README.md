# 工藤 崇 公式サイト

ファイナンシャル・プランナー事務所 代表 工藤崇のホームページです（1ページ構成）。
HTML と CSS だけで動くので、`index.html` をブラウザで開けばすぐに確認できます。

## 構成

1. ヒーロー（キャッチコピー）
2. 実績の数字（記名記事数・連載社数・面談数・PV）
3. プロフィール
4. 現在の活動（①〜⑤）
5. 主な執筆実績（注目記事・なんぼや・foriio）
6. ご相談いただける案件
7. お問い合わせ

## 編集のメモ

- 文章はすべて `index.html` にあります。各セクションは `<!-- ===== 〇〇 ===== -->` のコメントで区切っています。
- ゴールドオンラインの記事リンクは、今はサイトのトップ（`https://gentosha-go.com/`）になっています。記事のURLに差し替えてください。
- プロフィール写真は `images/profile.jpg` を置き、`about-photo` 内を `<img>` に差し替えます。
- サイトの色は `style.css` 冒頭の `:root` で変えられます。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages で、Branch を公開したいブランチ・`/ (root)` に設定すると
`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
