# 工藤 崇 ホームページ（ファイナンシャルプランナー・マネーライター）

執筆・監修の実績を中心に紹介する1ページのホームページです。
HTML と CSS だけで動くので、`index.html` をブラウザで開けばすぐに確認できます。

## 編集する場所

| 変えたいもの | 場所（`index.html`） |
| --- | --- |
| キャッチコピー・紹介文 | ヒーロー（ページ先頭） |
| 実績の数字（記事数・媒体数など） | `stats` セクションの `〇〇` |
| 経歴・保有資格・所属・得意分野 | `#about` |
| 主な掲載メディア | `#works` 内の `media-list` |
| 実績一覧 | `#works` 内の `works-list` |
| お仕事内容 | `#services` |
| メールアドレス・SNS | `#contact` |
| サイトの色 | `style.css` 冒頭の `:root` |

`〇〇` の部分や実績の記事タイトルはすべて仮の内容です。実際の内容に置き換えてください。

## 実績の追加方法

`works-list` の中に、次の1ブロックをコピーして追加します（上に追加すると新しい順に並びます）。

```html
<li data-category="執筆">
  <time>2026.10</time><span class="badge">執筆</span><span class="media">掲載メディア名</span>
  <a href="https://記事のURL">記事タイトル</a>
</li>
```

- `data-category` と `badge` には「執筆」「監修」「書籍」「取材・コメント」「セミナー・講演」のいずれかを入れます。
  - これらの分類で絞り込めます。
- 最初は10件だけ表示し、残りは「もっと見る」で10件ずつ表示します。

## 公開方法（GitHub Pages）

リポジトリの Settings → Pages で、Branch を公開したいブランチ・`/ (root)` に設定すると
`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
